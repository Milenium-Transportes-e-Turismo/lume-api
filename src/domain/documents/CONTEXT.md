# Documentos

Este contexto mantém o ciclo documental e suas evidências sem exigir que o
titular possua acesso ao sistema.

## Linguagem

**Titular Principal**:
Pessoa, empresa, vínculo, candidato, veículo, contrato, orçamento ou viagem à
qual o documento se refere principalmente.
_Evite_: Usuário obrigatório

**Relação Documental**:
Vínculo secundário entre um documento e outro contexto relevante.
_Evite_: Segundo titular principal

**Solicitação de Documento**:
Pedido para que um titular ou responsável apresente determinada evidência.
_Evite_: Documento recebido

**Arquivo Recebido**:
Conteúdo apresentado em resposta a uma solicitação, ainda sujeito à validação
quando exigida.
_Evite_: Documento validado

**Documento Gerado**:
Conteúdo produzido a partir de dados e modelo controlados pelo Lume.
_Evite_: Arquivo recebido

**Documento Assinado**:
Versão cuja assinatura foi comprovada conforme a regra do tipo documental.
_Evite_: Documento enviado para assinatura

**Versão Vigente**:
Versão reconhecida como atual conforme a regra do tipo documental, sem apagar
as versões anteriores.
_Evite_: Último arquivo enviado

**Pasta da Viagem**:
Conjunto documental iniciado no orçamento e preservado até as viagens que ele
originar.
_Evite_: Pasta isolada por departamento
