# Evidência manual antes de integração externa

Rotas, GPS, assinatura e confirmações de provedores externos serão registrados
manualmente nesta fase, sempre com origem e responsável. As interfaces futuras
aceitarão adaptadores externos sem mudar o significado do estado; presumir uma
confirmação automática sem evidência foi rejeitado para evitar que o Lume
declare como comprovado aquilo que uma pessoa apenas informou.
