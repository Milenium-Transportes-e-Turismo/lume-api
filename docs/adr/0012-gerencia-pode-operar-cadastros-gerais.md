# Gerência pode operar Cadastros gerais

As decisões SEC-01 B e SEC-02 A foram aprovadas: o teto de Gerência admite
`clients:view`, `clients:create` e `clients:update`, em vez de criar rotas
exclusivas para o ciclo temporário. As capacidades continuam sendo atribuídas
explicitamente por usuário e permitem usar as telas de Cadastros normais e
temporários; não incluem `clients:manage`, histórico, acesso comercial nem
autoridade administrativa.
