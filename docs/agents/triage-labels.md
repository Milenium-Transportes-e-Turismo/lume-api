# Etiquetas de triagem

As skills usam cinco papéis canônicos de triagem. Este arquivo relaciona esses papéis às etiquetas reais do rastreador deste repositório.

| Papel canônico    | Etiqueta no rastreador | Significado                                     |
| ----------------- | ---------------------- | ----------------------------------------------- |
| `needs-triage`    | `needs-triage`         | Precisa ser avaliada por uma pessoa mantenedora |
| `needs-info`      | `needs-info`           | Aguarda mais informações de quem abriu a issue  |
| `ready-for-agent` | `ready-for-agent`      | Está completamente especificada para um agente  |
| `ready-for-human` | `ready-for-human`      | Requer implementação ou decisão humana          |
| `wontfix`         | `wontfix`              | Não será implementada                           |

Quando uma skill mencionar um papel, use a etiqueta correspondente desta tabela.

Edite a coluna “Etiqueta no rastreador” se o vocabulário do repositório mudar.
